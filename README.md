# Rock Paper Scissors 

A simple Rock Paper Scissors game built with Python. 

## Features

* User plays against the computer
* Computer makes a random choice
* Detects win, lose, and tie
* Allows the user to play multiple rounds
* Handles invalid choices

## How to Run

Run the Python file:

```bash
python rock_paper_scissors.py
```

## Concepts Used

* `input()`
* `if / elif / else`
* `while` loop
* Lists
* `random.choice()`
* User input validation
